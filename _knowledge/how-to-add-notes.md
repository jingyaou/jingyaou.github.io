知识库里的每一篇文章，都是一个放在 `_knowledge` 文件夹中的 Markdown 文件。Markdown 是一种很简单的写作格式，不需要学习编程。

## 新建笔记

1. 打开网站的 GitHub 仓库。
2. 点击左侧的 `_knowledge` 文件夹。
3. 点击右上方的 **＋**，选择 **创建新文件**。
4. 文件名填写英文，例如 `banach-space.md`。
5. 复制下面的模板，然后替换标题、日期、分类和正文。
6. 点击绿色的 **提交更改**。

```markdown
---
title: 笔记标题
date: 2026-08-15
category: 实分析
description: 用一句话说明这篇笔记讲什么。
---

这里开始写正文。

## 一个小标题

这里继续写内容。
```

## 常用写法

用 `## 标题` 创建小标题，用 `- 内容` 创建项目列表。数学公式可以这样写：

```text
行内公式：$f(x)=x^2$

独立公式：

$$
\int_a^b f(x)\,dx
$$
```

提交以后，GitHub 通常需要几十秒生成新页面。刷新知识库首页，就能看到刚刚添加的笔记。
